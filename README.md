#### 🔨 Building now

**ApplyFlow**: swipe through jobs, and your own Claude writes the applications.
- Job feed fed by self-hosted scrapers across Greenhouse, Lever, Ashby and regional boards (DE / UK / ES / remote), running on Trigger.dev
- Near-duplicate ads folded into one card with MinHash; jobs embedded with ONNX models for matching
- Tailored CVs, cover letters and interview prep, with fact-checks for inflated scope and AI-sounding phrasing
- Self-hosted on Caddy, with Gatus monitoring and alerts for failing or silent pipelines

<sub>TypeScript · Python · PostgreSQL · Trigger.dev · Claude API</sub>
